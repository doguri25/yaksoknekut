약속네컷 — 윈도우 태블릿 자동 인쇄 버전
=================================================

이 폴더의 파일
  yaksok-necut.html   앱 본체 (안드로이드용과 같은 파일, 자동 인쇄 모드 포함)
  start-chrome.bat    크롬으로 실행 — 전체 화면 + 확인창 없이 자동 인쇄  ★ 권장
  start-edge.bat      엣지로 실행 — 크롬이 없을 때 사용
  test-window.bat     일반 창으로 열기 — 카메라·화면 점검용 (인쇄창은 뜸)

처음 한 번만 하는 준비 (5분)
  1. 프린터 연결
     셀피 CP1500을 USB로 태블릿에 연결하고 캐논 드라이버를 설치합니다.
     (Wi-Fi로도 가능: 설정 > 프린터 및 스캐너 > 장치 추가)
  2. 기본 프린터로 지정
     설정 > 프린터 및 스캐너 > 셀피 선택 > "기본값으로 설정"
     ("Windows에서 기본 프린터 관리" 옵션이 켜져 있으면 먼저 끄세요)
  3. 용지 기본값
     셀피 > 인쇄 기본 설정 > 용지 크기 = 엽서(4x6, 100x148mm), 테두리 없음(여백 없는 인쇄)
     여기서 정한 값이 자동 인쇄에 그대로 쓰입니다.
  4. 이 폴더를 바탕화면 등 아무 곳에나 두고 start-chrome.bat 을 더블클릭
     (크롬이 없으면 start-edge.bat)

행사 당일
  - start-chrome.bat 실행 → 대기 화면이 전체 화면으로 뜹니다.
  - [뽑기]를 누르면 인쇄창 없이 바로 프린터로 갑니다.
  - 교사 메뉴: 대기 화면 오른쪽 위 모서리를 5초 길게 누르기 → [테스트 인쇄]로 먼저 확인하세요.
  - 끝내기: 키보드 Alt+F4 (터치만 있으면 교사 메뉴 > 앱 종료)

잘 안 될 때
  - 카메라가 안 켜짐: test-window.bat 으로 열어 카메라 권한을 허용한 뒤 다시 실행.
                        (태블릿에 카메라가 앞뒤 두 개면 앞 카메라를 자동으로 씁니다)
  - 인쇄가 안 됨: 기본 프린터가 셀피인지, 셀피 전원·용지·잉크 카트리지를 확인.
                  크롬/엣지가 이미 다른 창으로 열려 있으면 모두 닫고 다시 실행하세요.
  - 사진이 잘리거나 작게 나옴: 3번 용지 기본값(엽서, 테두리 없음)을 다시 확인.
  - 글꼴이 딱딱해 보임: 인터넷이 연결되면 둥근 글꼴(Jua)이 자동으로 내려받아집니다. 없어도 동작에는 문제 없습니다.

사진은 어디에도 저장되지 않습니다. 교사 메뉴 설정만 이 태블릿에 남습니다.
