약속네컷 윈도우 앱 (1.11.1)
==========================

■ 실행
  약속네컷.exe 를 두 번 누르면 바로 시작됩니다. 설치 과정이 없습니다.
  전체 화면으로 열리고, 카메라 허용 창 없이 카메라가 켜지며,
  [뽑기]를 누르면 인쇄창 없이 윈도우 '기본 프린터'로 바로 출력됩니다.

■ 처음 한 번만
  1) 윈도우 설정 › 프린터에서 포토프린터를 '기본 프린터'로 지정
  2) 그 프린터의 기본 용지를 4×6(엽서)·테두리 없음(가로)으로 설정
  3) exe를 처음 열 때 "Windows의 PC 보호" 파란 창이 뜨면
     [추가 정보] → [실행] 을 누르세요 — 같은 폴더의 그림 '처음 실행할 때 - 파란 창이 뜨면.png' 를 보면 쉽습니다.
     (마이크로소프트에 유료 서명을 등록하지 않은 무료 앱이라 "모르는 앱"이라고 한 번 묻는 것이며, 바이러스가 아닙니다.
      다음부터는 뜨지 않고, 앱이 스스로 새 버전으로 바뀔 때도 다시 묻지 않습니다.
      파일에서 오른쪽 단추 › 속성 › 자세히 에 "약속네컷 · 도구리 · 홍북초등학교" 가 보이면 정품 파일입니다.)

■ 인쇄가 잘 안 될 때
  [뽑기] 뒤 프린터가 용지 없음·걸림·오프라인이면 화면에 "프린터를 확인해 주세요"가 크게 뜨고, 고치면 저절로 닫힙니다
  (기본 프린터 자동 출력일 때). 앱에 문제가 생기면 오류 화면이 뜨고 20초 뒤 스스로 다시 시작합니다(설정은 그대로).

■ 인쇄 방식 (프린터가 여러 대일 때)
  교사 메뉴 › 완성·인쇄 › '인쇄 방식'
    - 기본 프린터로 바로 출력 : [뽑기]를 누르면 확인창 없이 기본 프린터로 (기본값)
    - 프린터 선택창 뜨기      : [뽑기]마다 크롬 인쇄창이 떠서 프린터·용지를 고를 수 있음
  바꾸면 앱이 잠깐 닫혔다 다시 열리고, 다음 실행부터도 그대로 유지됩니다.
  ※ 기본 프린터인데 다른 프린터(알PDF 등)로 나간다면: 앱 안의 크롬이 '마지막에 쓴 프린터'를 기억하기 때문입니다.
     실행기 1.9.8부터는 켤 때마다 윈도우 기본 프린터와 맞춰 줍니다. 옛 실행기라면 인쇄 방식을 '프린터 선택창 뜨기'로
     바꿔 한 번 원하는 프린터로 인쇄한 뒤 다시 '기본 프린터로 바로 출력'으로 돌리면 됩니다.

■ 잠금 비밀번호
  교사 메뉴 › 잠금 › '잠금 비밀번호'에서 숫자 4자리를 정하면
  앱을 켤 때와 교사 메뉴에 들어갈 때 번호판이 뜹니다 (기본은 꺼짐).
  잠금 화면 오른쪽 위 [종료]로 잠긴 채 앱을 끌 수도 있습니다.
  첫 화면 오른쪽 위 [잠금] 단추와 교사 메뉴 왼쪽 아래 [저장하고 잠그기]로 바로 잠글 수 있고,
  '가만히 두면 잠금'(3·5·10·30분)을 켜면 아무도 만지지 않을 때 스스로 잠깁니다.
  비밀번호를 잊었다면: 앱을 끄고 %LOCALAPPDATA%\YaksokNecut 폴더를 통째로 지운 뒤 다시 켜세요
  (모든 설정이 처음으로 돌아갑니다).

■ 사진 품질 (교사 메뉴 › 촬영 › '사진 품질')
  고화질(1920) · 연속 3장 중 선명한 것 · 자동 밝기·색 보정 · 인쇄용 선명하게 — 각각 켜고 끌 수 있습니다.
  기본은 모두 켬, '연속 3장'만 꺼짐 (아이들이 움직여 흐린 사진이 자주 나오면 켜세요).
  느린 컴퓨터·태블릿에서 카메라 화면이 버벅이면 고화질을 끄세요.

■ 끝내기
  화면 오른쪽 위의 작은 [× 종료] 단추 → [종료]  (촬영 중·교사 메뉴에서는 안 보임)
  (교사 메뉴 왼쪽 아래 [앱 종료], 키보드 Alt+F4 도 됩니다)

■ 모니터가 두 개일 때 (교실 컴퓨터 + 전자칠판)
  모니터가 둘 이상이면 앱은 두 번째 모니터(전자칠판·프로젝터 쪽)에서 열립니다.
  첫 화면 오른쪽 위 [○번 모니터로 옮기기] 단추나
  교사 메뉴 왼쪽 아래 [○번 모니터 → ○번으로] 또는 화면 › '앱을 보여줄 모니터'에서 바꿀 수 있고, 고른 모니터는 기억됩니다.
  (설정 파일: %LOCALAPPDATA%\YaksokNecut\config.txt)

■ 업데이트 (앱 파일과 실행기 모두 스스로)
  업데이트 주소는 기본으로 GitHub 저장소(doguri25/yaksoknekut)의 index.html 을 봅니다.
  켤 때는 파일 앞부분의 버전 표시만 읽어(0.1초쯤) 새 버전이 있을 때만 내려받습니다. 망이 느려 6초 안에 못 받으면
  뒤에서 받아 두고 첫 화면 오른쪽 위 [새 버전 준비됨 · 다시 시작]으로 안내합니다(안 눌러도 다음에 켤 때 적용).
  교사 메뉴 › 학교·기록·앱 › 업데이트 › [업데이트 확인] → [지금 업데이트] 로 몇백 KB만 받아 바로 새 버전이 됩니다.
  '앱을 켤 때 자동으로 바꾸기'를 켜면 실행할 때마다 스스로 확인합니다.
  잘못되면 [이전 버전으로 되돌리기].  (설정: %LOCALAPPDATA%\YaksokNecut\config.txt 의 update_url)
  실행기(약속네컷.exe)도 새 버전이 있으면 켤 때 뒤에서 조용히 받아 둡니다. 받아 두면 첫 화면 오른쪽 위에
  [실행기 새 버전 · 다시 시작] 단추가 뜨고, 누르면 3초쯤 뒤 새 실행기로 켜집니다(설정은 그대로). 안 눌러도 다음에 켤 때 적용되고,
  첫 화면에서 3분 동안 아무도 만지지 않으면 10초 카운트다운 뒤 알아서 다시 시작합니다(만지면 취소 · 교사 메뉴 › 업데이트에서 끌 수 있음).
  [지금 업데이트]를 누른 경우엔 바로 새 실행기로 이어집니다. 옆에 남는 약속네컷.old.exe 는 다음 실행 때 지워집니다.
  (exe가 있는 폴더에 쓰기 권한이 없으면 안내가 뜨니, 바탕화면 등 쓸 수 있는 곳에 두세요)

■ 글꼴
  제목·단추는 주아체, 본문(안내 글·교사 메뉴)은 교사 메뉴 › 화면 › '본문 글꼴'에서 9가지 중 고릅니다 (기본 메이플스토리체).
  메이플스토리체 · 넥슨 Lv.2 고딕 · 나눔스퀘어라운드 · LINE Seed KR · 학교안심 바른돋움 · 학교안심 몽글몽글 · 쿠키런 · 강원교육모두체 · 티머니 둥근바람
  모두 앱 파일 안에 들어 있어 인터넷 없이도 같은 모양으로 나옵니다. 사진(인쇄물)의 글씨는 주아체 그대로입니다.

■ 교사 메뉴
  대기 화면 로고를 누르면 나오는 [교사 설정] 버튼, 또는 화면 오른쪽 위를 5초 누르기.
  왼쪽 세로 메뉴: 자주 쓰는 설정 · 행사 세트 · 약속 문장 · 촬영 · 완성·인쇄 · 소리 · 화면 · 학교·기록·앱
  설정은 이 컴퓨터의 다음 폴더에 저장되어 다음 실행 때도 유지됩니다.
    %LOCALAPPDATA%\YaksokNecut\    (앱 파일과 설정 · 지워도 됨, 지우면 설정이 초기화됨)
  설정은 settings.json 에 저장되어 브라우저 저장소가 지워져도 유지됩니다.
  교사 메뉴 › 학교·기록·앱 › [설정 코드 복사]로 설정을 코드 한 줄로 백업하고, [코드로 복구]로 되살릴 수 있습니다
  (다른 컴퓨터에 같은 설정을 옮길 때도).

■ 어떻게 돌아가나
  이 exe는 안에 든 약속네컷 앱을 풀어서 컴퓨터에 설치된 크롬(없으면 엣지)을
  '키오스크 + 자동 인쇄' 모드로 띄웁니다 (인쇄 방식을 '프린터 선택창'으로 바꾸면 자동 인쇄 없이 띄움). 윈도우 10·11에는 엣지가 기본으로 있어
  따로 설치할 것이 없습니다. 크롬이 있으면 크롬을 우선 씁니다.

■ 인화지 잔량 · 다시 뽑기 · 대기 화면
  교사 메뉴 › 완성·인쇄에서 인화지 팩을 넣을 때 [+36] 등을 눌러 두면 인쇄마다 줄고 5장 이하면 첫 화면에 표시됩니다.
  같은 곳의 '마지막 사진'에서 방금 인쇄한 사진을 한 장 더 뽑을 수 있습니다(앱을 끄면 사라짐).
  화면 › 대기 화면을 켜면 첫 화면에서 한동안 아무도 안 만질 때 액자 예시가 넘어갑니다.

■ 약속 손글씨
  꾸미기 › 약속 탭 › [손글씨로 쓸래요]: 화면에 손가락·펜으로 쓴 글씨가 약속 칸에 그대로 인쇄됩니다 (전자칠판·터치 태블릿).

■ 잘 안 될 때
  - 인쇄가 안 나옴: 기본 프린터가 포토프린터인지, 켜져 있는지 확인
  - 카메라가 안 켜짐: 다른 앱(카메라, 줌 등)이 카메라를 쓰고 있지 않은지 확인
  - 음성이 안 나옴: 윈도우 설정 › 시간 및 언어 › 음성 › 한국어 음성 추가
  - ARM 기반 윈도우 태블릿(Surface Pro X 등)이면 별도 빌드가 필요합니다. 알려주세요.
