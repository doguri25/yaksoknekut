# 약속네컷

초등학교 학교폭력예방·생활교육 행사와 교실에서 쓰는 네컷 포토부스 앱입니다. 아이들이 친구와 사진을 찍고 스티커·약속 문장으로 꾸민 뒤 4×6 사진으로 뽑아, 사진 아래 여백에 자기 약속을 써서 게시판에 붙입니다. 사진은 어디에도 저장되지 않습니다.

- **앱 파일**: [`index.html`](index.html) — 브라우저로 열면 바로 동작하는 한 파일 앱 (최신 버전)
- **윈도우 앱**: `약속네컷.exe` — [Releases](../../releases)에서 `약속네컷-윈도우앱.zip` 을 받아 풀고 exe 실행 (설치 없음, 카메라 자동 허용, 확인창 없는 자동 인쇄, 전자칠판 모니터 자동 선택)
- **안내서**: [교사용 설치·운영 안내서 (PDF)](docs/약속네컷_교사용_설치운영_안내서.pdf) · [학생용 안내 포스터 (A4)](docs/약속네컷_학생용_안내_포스터.pdf)

## 업데이트

윈도우 앱은 교사 메뉴 › 화면·테마 › 업데이트에서 [업데이트 확인] → [지금 업데이트] 를 누르면 이 저장소의 `index.html` 을 받아 새 버전으로 바뀝니다. "앱을 켤 때 자동으로 바꾸기"가 켜져 있으면 실행할 때 스스로 확인합니다. 배포하는 쪽은 새 `index.html` 을 `master` 에 올리기만 하면 됩니다.
